# 羽毛球 · 双打大轮转 · 工作台

一个纯前端（单 HTML 文件）的**羽毛球双打大轮转**赛程生成与记分演示工具。打开网页即可输入人数与场地片数，自动生成完整赛程、播放轮转动画，并支持大分/小分记分与实时排行榜。

- 演示文件：`badminton_rotation.html`（双击浏览器打开，无需任何依赖）

---

## 一、功能总览

| 功能 | 说明 |
| --- | --- |
| 人数输入 | 任意 ≥ 4 人（4 ~ 40） |
| 场地片数 | 1 ~ 10 片，仅影响并行度 |
| 总局数 | 由算法自然给出，与场地片数无关 |
| 每轮并行 | `min(场地数, ⌊人数 / 4⌋)` 片，每片各打 1 场 |
| 赛程生成 | 业内「双打大轮转 / 八人转 / 多人转」标准算法 |
| 动画播放 | 播放 / 暂停 / 上一轮 / 下一轮 / 重置，速度可调 |
| 记分 | 每局录入比分，胜方 +1 大分；双方各按实际比分累计小分 |
| 排行榜 | 大分优先，大分相同比小分，实时刷新 |
| 轮空 | 人数非 4 倍数时自动显示本轮轮空人员 |
| 搭档进度 | 矩阵可视化，绿色格子 = 已搭档过的队友 |

---

## 二、轮转算法说明

采用业内标准的「双打大轮转」贪心算法：

1. 列出全部 `C(N,2)` 个搭档组合，以及全部可能对局（队 vs 队，4 人互不重叠）；
2. 每局按「未使用过的搭档 + 上场次数少的人」优先挑选对阵上场；
3. 终止条件：**每对搭档都至少上场一次 且 每人上场次数完全相等 时停止**。

该算法保证每人上场次数极差为 0（完全均衡），且总局数与场地片数无关。

## 四、记分与排名规则

| 项目 | 规则 |
| --- | --- |
| 大分 | 每胜一局，胜方两人各 +1 大分 |
| 小分 | 按该局实际比分累计，胜方两人各加本方得分，负方两人各加本方得分 |
| 示例 | 比分 21 : 15 → 胜方两人各 +21 小分，负方两人各 +15 小分 |
| 排序 | 先按大分降序；大分相同再比小分；仍相同则按选手序号 |
| 并列 | 大分与小分都相同者同名次 |

## 六、使用方法

1. 用浏览器打开 `badminton_rotation.html`；
2. 在顶部输入「人数」与「场地片数」，点击 **应用 / 重新生成**；
3. 点击 **▶ 播放** 观看轮转动画，或用 **上一轮 / 下一轮** 手动切换；
4. 在当前轮每片场地的比分框录入比分并点 **确认**（或点 **🎲 随机本轮比分** 快速演示）；
5. 下方 **🏆 实时排行榜** 会按「大分 → 小分」自动排序。
