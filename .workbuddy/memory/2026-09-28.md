## 轮空（bye）处理补充
- 用户要求支持非 4 倍数人数下的轮空。数学前提：要保证「每对恰好搭档一次」，人数 N 必须 ≡0 或 1 (mod 4)；N≡2/3 时总局数 N(N−1)/4 非整数，完美覆盖不可能。
- 算法改为对 K_N 做 1-因子分解：偶数 N → N-1 轮、无人轮空；奇数 N(4k+1) → 补虚拟人做分解，每轮恰好 1 人轮空（与虚拟人配对者），N 轮。
- 非法人数用 adjustN() 取最近合法值（4 的倍数或 4k+1）并提示原因。
- 排行榜新增「轮空」列，按 matching(mid) 去重计数（避免单场地串行时同一轮被重复计）。
- 校验：N=4/5/8/9/12/13 覆盖零重复、奇数每人轮空恰好 1 次、偶数 0 次；矫正 6→5/7→8/10→9/11→12/14→13 均正确。
